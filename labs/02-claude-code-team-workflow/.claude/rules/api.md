# API 実装ルール

## 対象ファイル

`src/api/**/*`

## エンドポイント設計

- RESTful 規約に従う
- パスは小文字のケバブケース (`/customer-orders` など)
- レスポンスは常に JSON を返す

## セキュリティ

- すべてのエンドポイントは認証を要求する (public endpoint は明示的に例外指定)
- ユーザー入力は必ず検証する
- SQL インジェクション・XSS 対策を徹底する

## エラーレスポンス

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "ユーザー向けメッセージ",
    "details": {}
  }
}
```

## レート制限

- 外部向け API にはレート制限を設ける
- `X-RateLimit-*` ヘッダーを返す

## ログ

- リクエスト・レスポンスのログを記録する (個人情報は除外)
- エラー時は `ERROR` レベルで記録する
