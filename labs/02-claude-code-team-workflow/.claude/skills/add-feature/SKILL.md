# Skill: Add Feature

## 説明

新機能を TDD (テスト駆動開発) で追加するための標準フローです。

## context: fork

このスキルは独立したコンテキストで実行します。
親の変更履歴を引き継がないことで、クリーンで予測可能な実行を保証します。

## 使用場面

- 新しい API エンドポイントの追加
- 新しいツール関数の実装
- 新しいビジネスロジックの追加

## 手順

1. **要件の確認**
   - 追加する機能の入力・出力・エラーケースを明確にする
   - 既存のコードへの影響範囲を確認する

2. **テストを先に書く**
   - `tests/` に対応するテストファイルを作成する
   - ハッピーパス・エラーパスのテストを書く
   - Gate / 境界値のテストを必ず含める

3. **最小実装**
   - テストが通る最小限のコードを書く
   - CLAUDE.md の禁止事項を守る

4. **テスト実行**
   ```bash
   pytest tests/ -v
   ```
   すべてのテストが通ることを確認する

5. **リファクタリング**
   - コードを整理する (40 行以内の関数)
   - 型ヒントを追加する
   - docstring を書く

6. **最終確認**
   - CLAUDE.md の規約に沿っているか確認する
   - カバレッジが 80% 以上か確認する
   - API キーなどのハードコードがないか確認する
