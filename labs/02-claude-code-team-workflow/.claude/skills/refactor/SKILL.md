# Skill: Refactor

## 説明

既存コードを安全にリファクタリングするためのスキルです。
**必ず plan mode を使用してください。**

## context: fork

このスキルは独立したコンテキストで実行します。
リファクタリング対象以外の変更が混入しないようにします。

## 重要: plan mode の使用

リファクタリングは不可逆的な変更を伴う可能性があります。
実行前に必ず plan mode で変更計画を確認してください。

```bash
# plan mode での実行
claude --plan "src/agents/ のリファクタリングを実施"
```

## 使用場面

- 関数の分割・整理
- モジュール構成の変更
- 命名規則の統一

## 手順

1. **現状確認**
   - リファクタリング対象のコードを把握する
   - テストカバレッジを確認する (`pytest --cov`)
   - テストが通っていることを確認する

2. **plan mode で計画作成**
   - 変更箇所と影響範囲をリストアップする
   - テストへの影響を確認する

3. **計画の承認を得てから実行**
   - 計画を確認し承認する
   - 変更を適用する

4. **テスト実行**
   ```bash
   pytest tests/ -v
   ```
   リファクタリング前後でテストが通ることを確認する

5. **差分確認**
   - `git diff` で変更内容を確認する
   - 意図しない変更が含まれていないか確認する
