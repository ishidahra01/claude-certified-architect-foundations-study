# src/ ディレクトリのルール

このディレクトリには本番コードを配置します。
project-level の CLAUDE.md に加えて、以下のルールが適用されます。

## src/ 固有のルール

- すべてのモジュールに `__init__.py` を配置する
- 外部に公開する API は `__all__` で明示的にエクスポートする
- 循環インポートは禁止

## パッケージ構成

```
src/
  agents/      ← エージェント実装
  tools/       ← ツール関数
  models/      ← データモデル (Pydantic)
  api/         ← API エンドポイント (api.md ルール適用)
```

## 本番コードの注意事項

- デバッグ用の `print()` は残さない (ロガーを使用)
- 環境変数は `os.environ.get()` で取得し、デフォルト値を設定する
- タイムアウトを必ず設定する (外部 API 呼び出し等)
